## Fork rule: never contribute to upstream

This is a personal fork (ajmariduena/faceclaw) of jimrandomh/faceclaw. Never
open pull requests, issues, comments, or reviews on jimrandomh/faceclaw, and
never push to the `upstream` remote. `upstream` is fetch-only, used solely to
pull changes in with `git fetch upstream && git merge upstream/main`. All
pull requests target ajmariduena/faceclaw. This applies even when a change
looks like a good upstream contribution: record it in research/ instead.

Project overview, build and test instructions are in CLAUDE.md.
